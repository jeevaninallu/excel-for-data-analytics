# 📊 Excel Salary Dashboard

A dynamic and interactive Excel dashboard built to analyze Data Science job salaries across different job roles, countries, and work schedules using charts, formulas, and data validation.

> ⚠️ **Learning Project:** This project was recreated by following **Luke Barousse's Excel for Data Analytics Course**. The implementation was completed independently for educational purposes and to strengthen my Excel data analytics skills.

---

# Project Overview

The goal of this project is to help users explore and compare salary trends for Data Science jobs through an interactive Excel dashboard.

The dashboard allows users to filter salaries based on:

- 🌍 Country
- 💼 Job Title
- 🕒 Job Schedule Type

Users can quickly compare salaries across different job roles and countries through interactive visualizations.

# 📖 Key Insights

Some observations from the dashboard include:
