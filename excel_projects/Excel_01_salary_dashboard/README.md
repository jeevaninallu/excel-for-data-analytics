Excel Salary Dashboard
Overview

This project is a recreation of an Excel Salary Dashboard built as part of Luke Barousse's Excel for Data Analytics course. I followed the tutorial to strengthen my Excel data analytics skills and understand how interactive dashboards are designed.

The project analyzes salary data for various data-related job roles using Excel dashboards.

Credit: Original project concept and tutorial by Luke Barousse. This repository is my personal learning implementation and is intended for educational purposes only.
